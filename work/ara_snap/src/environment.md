# Environment

- **Python**: 3.12.13 for the CPU estimation, bootstrap and permutation kernels (Appendix D.2); the released package declares `requires-python >= 3.9` (pyproject.toml).
- **Framework**: NumPy 2.0.2 (bootstrap streams tied to this version's default generator); SciPy >= 1.10, pandas >= 2.0, PyYAML >= 6.0, tqdm >= 4.65 (requirements.txt). Scoring: transformers 4.57.1 pinned; torch 2.10.0 on Kaggle T4 images and 2.14.0 on the RTX 3090 runs of the registered test. compute2 README additionally pins ai2-olmo 0.6.0 (no dependency resolution) and torch >= 2.8 with a CUDA 12.8 build for RTX 5090s; the paper reports the PolyPythias battery and second bank scored on Kaggle T4 cards, not on 5090s.
- **Hardware**: Primary Arm 1 on one Kaggle CPU core (6.0 hours for estimation and null checks, 1.6 hours for four sensitivity tasks); registered test on Kaggle T4 cards (205 runs) and three RTX 3090 cards (last 20 runs at 1B, 6,068 seconds); earlier transport scoring on one 46 GB L40S per job on a Slurm cluster (27 jobs under two minutes each), T4 for rescore and 160M checkpoint check (423 seconds); PolyPythias battery and bank 2 on Kaggle T4 cards in float32.
- **Key dependencies**: numpy, scipy, pandas, pyyaml, tqdm; optional gpu extras torch >= 2.0, transformers >= 4.40, datasets >= 2.18; hub extras huggingface_hub >= 0.23, pyarrow >= 14.0 (pyproject.toml). OLMES harness at commit 5a51f502d463b8cdc4a2dcad7d7096c41ff1197e for bank 2 (compute2/config/banks.json); the held-out tasks use "the OLMES harness at a pinned commit" (Appendix C), whose hash is Not available from provided input.
- **Random seeds**: master seed 20260101 (half split); bootstrap seed 0; calibration seeds 20260963, 20260971, 20260972, 20260978 for listed sweeps; bank-2 subsample seed 20260921 (compute2/config/banks.json).
- **Data**: DataDecide release streamed as 122.9 GB of gzipped JSONL tarballs; reductions about 48 MB of NumPy archives; release repository `allenai/DataDecide-eval-instances` for request files (banks.json).
- **Released artefacts**: per-item reductions, item ordering and half assignments, selected checkpoint identifiers, analysis scripts; registered-test protocol with dated amendments, frozen request-file hash, scoring and analysis kernels; frozen hashes of both bank request files.
